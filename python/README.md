# Fake News Detection Using Machine Learning — Python / Flask Reference Implementation

This folder contains the complete academic implementation of the project using
**Python, Pandas, NumPy, Scikit-learn, NLTK and Flask**. It is self-contained: train the
model, then run the Flask server to get the web application.

> The React application in the parent repository is the deployed demo and runs the exact
> same pipeline (cleaning → TF-IDF → Logistic Regression) in TypeScript so it can be hosted
> without a Python server.

## 2. Dataset

**Kaggle — Fake and Real News Dataset**
<https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset>

| File     | Rows   | Description         |
| -------- | ------ | ------------------- |
| True.csv | 21,417 | Genuine news        |
| Fake.csv | 23,481 | Fabricated news     |

Columns: `title`, `text`, `subject`, `date`.
`train_model.py` adds `label` (REAL = 0, FAKE = 1) and merges `title + text` into `content`.

Place both CSV files inside `python/dataset/`.

## 4. Train the model

```bash
python train_model.py
```

This performs preprocessing, TF-IDF feature extraction, trains Logistic Regression,
Multinomial Naive Bayes and Random Forest, prints the classification reports, writes the
graphs to `results/` and saves the best model to `model/model.pkl` plus the fitted
vectorizer to `model/vectorizer.pkl`.

## 5. Run the web application

```bash
python app.py
```

Open <http://127.0.0.1:5000> in a browser.

## 6. REST API

`POST /api/predict`

```json
{ "text": "SHOCKING! Doctors are furious about this miracle cure!!!" }
```

Response:

```json
{
  "success": true,
  "label": "FAKE NEWS",
  "prediction": 1,
  "confidence": 97.42,
  "fake_probability": 0.9742
}
```

`GET /api/history` returns the last 20 logged predictions from `predictions.db`.

Test with curl:

```bash
curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"text":"The finance ministry said the new tax framework will apply next year."}'
```

## 7. Workflow

1. Load `True.csv` and `Fake.csv`, label and shuffle.
2. Clean text: lowercase → remove URLs/HTML/punctuation/digits → stop words → stemming.
3. TF-IDF vectorization (`stop_words='english'`, `max_df=0.7`).
4. 80/20 stratified train–test split (`random_state=42`).
5. Train Logistic Regression, Naive Bayes and Random Forest.
6. Evaluate: accuracy, precision, recall, F1-score, confusion matrix.
7. Save the best model and the vectorizer with `joblib`.
8. Flask loads them at startup and serves `/api/predict`.
9. Frontend validates input, calls the API and renders the label with confidence.
10. Every prediction is logged into SQLite.

## 8. Typical results

| Model               | Accuracy | Precision | Recall | F1-score |
| ------------------- | -------- | --------- | ------ | -------- |
| Logistic Regression | ~0.96    | ~0.96     | ~0.96  | ~0.96    |
| Multinomial NB      | ~0.93    | ~0.93     | ~0.93  | ~0.93    |
| Random Forest       | ~0.96    | ~0.96     | ~0.95  | ~0.96    |

Exact numbers depend on the dataset version and the random split.

## 9. Troubleshooting

- `Model files not found` → run `python train_model.py` before `python app.py`.
- NLTK `LookupError` → run `python -c "import nltk; nltk.download('stopwords'); nltk.download('punkt')"`.
- `FileNotFoundError: dataset/True.csv` → download the dataset from Kaggle into `dataset/`.
